# Decoding Music Perception: EEG-Based Genre Classification


## Requirements

To compile the thesis, ensure you have the following installed:
- **LaTeX distribution** (e.g., TeX Live, MiKTeX, or MacTeX)
- **BibTeX** or **biber** for bibliography management
- A LaTeX editor (e.g., Overleaf, TeXShop, or VS Code with LaTeX extensions)

## Compilation Instructions

1. Clone this repository:
  ```bash
  git clone <repository-url>
  cd BachelorThesis
  ```

2. Compile the `thesis.tex` file using your preferred LaTeX editor or the command line by making use of the attached Makefile:
  ```bash
  make
  ```

3. The compiled PDF will be available in `build/thesis.pdf`.
